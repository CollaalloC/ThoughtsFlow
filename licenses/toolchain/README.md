# Rust standard library notices

`COPYRIGHT-library.html` and `licenses/` are unmodified notice files from the
Rust 1.97.1 standard-library distribution used for the initial local build.
The HTML references the license texts in the sibling directory. ThoughtsFlow
does not distribute the Rust compiler.

Official source: https://github.com/rust-lang/rust/tree/1.97.1

Every release builder must refresh these files from its actual Rust toolchain
before packaging if its compiler version differs.
