# 按请求身份提交异步结果

架构审查发现，工作区的旧请求可覆盖新视图，Orca 重连也可能在返回身份核验前就留下成功回执。异步结果必须归属于发起时的工作区会话、确切 Dispatch 或 Agent Operation；到达顺序不能决定其归属。

前端使用工作区会话身份、读请求代次和当前发送身份决定哪些结果可以更新界面，不通过切换界面来取消后端运行。Agent 控制先保存 pending 意图和原始回执，按具体动作校验身份，再用一个本地事务发布 Operation 与相关 Mission / Binding。不同 Mission 使用独立锁，同一 Mission 保持串行。

此选择保留了现有 Interface 与数据 schema，代价是必须明确区分旧响应、未确认外部结果和本地提交失败。我们不通过全局阻塞、自动重试或分布式事务隐藏这些状态。Orca 仍是执行生命周期权威，符合 ADR 0001。
