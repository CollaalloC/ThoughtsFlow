# ThoughtsFlow v0.1.0-beta.3

本测试版把 Agent 工作台迁移到 herdr-core，复用现有 Agent 模板与模型配置。旧 Orca 协作保留为只读历史。

## 主要变化

- 工作区 → 选择上下文与证据 → 预览交接 → 原生 Agent 执行 → 保存观察 → 复用证据，无需另设 Provider。
- 通过 herdr-core JSON-RPC 使用真实 Agent harness，保留准确 core/终端身份、首条消息回执与未知结果防重派规则。
- schema 11 新增不可变执行关联；历史 Context Receipt、交接、输出和 hash 保留。
- 历史摘要分页、按需读取正文，保留导航草稿，修复异步结果覆盖较新界面的竞态。

## 首次使用和升级

1. 单独安装兼容的 herdr-core（已核实最低 0.1.17）和配置好的 Agent。模板设置见 README；Windows 模板需要 sh，例如 Git for Windows。
2. 备份旧数据库后升级。应用沿用原应用标识和数据库位置；不要用旧版直接打开已经升级的数据库。
3. 连接 herdr-core，选择本地工作目录和模板，再预览并派发任务。需要隔离文件时请选择独立 checkout；不自动创建 worktree 或合并代码。
4. 原生 Agent 的权限/信任对话继续在其原生界面处理。Agent 自报完成或进程退出不等于任务验收通过。

## 验证范围

macOS 已通过真实 herdr-core 0.1.17 + OMP 18.16.0 两阶段工作流：继承 gpt-6-astra / xhigh 配置，验证上下文、实际文件执行和不可变证据复用。正常 CI 仅使用固定 fixture，不包含模型凭据。发布页面将附本次三平台 CI 与四目标安装包构建的实际运行链接。

构建/fixture 成功不代表 Windows/Linux 真实模型工作流已经验收，也不代表每个模型供应商都已经测试。

## 安装包和限制

- macOS Apple Silicon、macOS Intel：DMG 和保留权限的 app.tar.gz。
- Windows x64：NSIS EXE；缺少 WebView2 时安装器可能需要联网。
- Linux x64：DEB，依赖系统 GTK/WebKit，不是所有发行版通用的便携包。
- 本测试版没有可信发布者证书，macOS 未公证。系统可能提示未知开发者；不要关闭系统范围的安全设置。
- herdr-core、Agent 和模型不随安装包提供；没有自动更新器。

请核对 SHA256SUMS.txt；build-*.json 记录每个安装包的源码提交与构建工作流。安装包附 MIT 主项目许可、第三方声明、必要许可文本与源代码归档。herdr-core 作为外部运行时遵循 Apache-2.0，OMP/历史 Orca 的参考声明继续保留。
